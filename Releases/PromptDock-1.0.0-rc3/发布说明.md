# PromptDock 1.0.0 RC3（Build 2）

## 下载与校验

- 安装包：`PromptDock-1.0.0-rc3.dmg`
- SHA-256：`126dd3517c3c6678a2dbbf10ac36faf90a715fab337e940e681ace926dc100c6`
- 系统要求：macOS 14 或更新版本
- 支持芯片：Apple Silicon 与 Intel

在终端中可使用以下命令核对下载文件：

```bash
shasum -a 256 PromptDock-1.0.0-rc3.dmg
```

输出应与上面的 SHA-256 完全一致。

## 安装与升级

1. 打开 DMG，将 PromptDock 拖入“应用程序”。
2. 从旧版本升级时，在 Finder 提示后选择“替换”。
3. 首次启动若被 macOS 拦截，请在“应用程序”中右键 PromptDock，选择“打开”，再确认一次。
4. 不要关闭 Gatekeeper，也不要修改全局系统安全设置。

升级前建议在 PromptDock 的“设置 → 隐私”中导出 JSON 备份。RC3 沿用相同的 Bundle Identifier、App Group、SwiftData V1、偏好设置和 Keychain 服务，覆盖安装应保留原有提示词、分类、设置与 API Key。

## RC3 主要变化

- 支持 `{{变量}}` 填写后复制与实时预览。
- 支持最多 100 项的 `{{变量[]}}` 可重复变量。
- 增加应用内模板语法手册。
- 增加可选的 DeepSeek / OpenAI 兼容接口模板生成。
- API Key 保存到 macOS Keychain。
- AI 请求发送前必须由用户明确确认。
- 改进 AI 请求取消与错误处理。

## AI 与隐私

- 提示词库、分类、本地图片和备份默认只保存在本机。
- API Key 保存到 Keychain，不进入 JSON 备份。
- 只有用户确认在线生成后，当前输入的需求和模板语法手册才会发送给所选服务商。
- 已保存的提示词库、分类和本地图片不会随 AI 请求发送。
- AI 服务的保留、计费和隐私规则由用户选择的服务商决定。
- PromptDock 当前不包含账号、广告、分析、跟踪或云同步。

## 已知限制

- Personal Team 构建未经过 Apple 公证，其他 Mac 首次启动可能出现 Gatekeeper 提示。
- 当前没有自动更新；新版本通过 Finder 覆盖安装。
- RC3 仅支持 macOS，不包含 Windows、iPhone 或 iPad 客户端。
- Early Access 使用用户自己的 DeepSeek 或兼容服务 API Key。
