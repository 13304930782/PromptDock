# PromptDock 网站展示素材

`PromptDock-1.2.0-main-window.png` 是 1.2.0 build 7 在 macOS 上实际运行的窗口截图（2880 × 1582），可用于网站展示。通过系统窗口截图取得，没有重新绘制界面。

`PromptDock-practical-prompts.json` 是可导入的格式 2 备份，包含 10 条实用提示词模板、4 个内置分类、3 个标签、1 个教学智能集合和模板变量定义。涵盖英语作文批改、教案、分层练习、会议纪要、更新说明、文案润色、Bug 定位、接口测试、摘要及需求拆解。

在 PromptDock 的备份设置中选择“合并导入”可添加这些模板。JSON 仅包含本次编写的公开模板，不包含原有私人资料库、API Key 或本机数据库。展示数据不会内置进 DMG，也不会覆盖安装者的资料库。

本次本机整理保留了原有 React 代码审查提示词，删除了 7 条已核对的测试提示词、3 个测试分类及名为 `test` 的智能集合。操作前已完整备份到本机 `LocalBackups/PromptDock-before-showcase-20261015/`；该目录不应上传 GitHub。
